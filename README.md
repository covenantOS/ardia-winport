# ardia-winport

Windows port skeleton for https://github.com/mantrakp04/ardia (Chromium 157 + Helium).

Delta over upstream commit 3a8a85f (mantrakp04/ardia main, 2026-11-11):

- `engine/patches/series.win` — upstream `series` minus 8 mac-only patches, plus 4 `.win` variants.
- `engine/ardiacore-win/` — `assert(is_win)` GN layer; C++ stubs for the embedder hook symbols.
- `engine/chromium-win/` — `assert(is_win)` BUILD for `//chrome/browser/ardia`; `ac_pip_win.cc` replaces Cocoa PiP.

Apply onto a helium-windows-fetched Chromium tree: copy these files into the ardia checkout, run `engine/chromium-win/apply.sh` and `engine/ardiacore-win/apply.sh` per upstream `docs/engine-build.md`, then apply series.win patches via quilt/patch in series order.

Generated by an agent; see `engine/ardiacore-win/REPORT.md` for the symbol table and verification notes.
